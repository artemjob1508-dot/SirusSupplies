SirusSupplies 0.5.0: учёт сумки при выкупе реагентов
Обзор аддона, внесённые изменения и идеи для дальнейшего развития
Доработанная версия аддона упакована в архив SirusSupplies_0.5.0.zip. В игре она не запускалась: интерпретатора Lua в среде не было, поэтому проверен только баланс блоков и скобок во всех файлах.
Что за аддон
SirusSupplies считает, во сколько обойдётся выкуп реагентов для поставок Джулии на аукционе Sirus (3.3.5a). Аддон состоит из пяти файлов:
• Core.lua — база, утилиты, цветовая градация цен (до 500g зелёный, до 800g жёлтый, дальше красный), команды /sup.
• Learn.lua — учится спискам реагентов из журнала заданий и из диалога Джулии. Серверные списки в клиенте недоступны, поэтому каждую поставку нужно один раз взять.
• Prices.lua — сканирует минимальную цену за штуку через C_AuctionHouse (на старом 3.3.5 — через QueryAuctionItems).
• Buy.lua — выкупает самые дешёвые лоты через StartCommoditiesPurchase и ConfirmCommoditiesPurchase.
• UI.lua — окно у аукциона, кнопка на миникарте и панель с ценами у Джулии.
Что добавлено
• Чтение сумки. Аддон читает сумки 0–4 при открытии аукциона, перед сканом и при каждом изменении сумок. Считает по названию из ссылки на предмет и по itemID.
• План по каждой поставке. Для неё показывается один из трёх вариантов:
    ◦ «Купить» — в сумке ничего нет, выкуп целиком.
    ◦ «Докупить» — часть уже есть; в подсказке видно «есть N, купить M — сумма».
    ◦ «в сумке» — всё есть; кнопка неактивна, покупать нечего.
• Скан цен только по недостающему. Реагенты, которые уже лежат в сумке, на аукционе не запрашиваются. Скан идёт быстрее, а устаревшие цены на «закрытые» реагенты не вызывают лишних автосканов.
• Покупка ровно недостающего количества. В окне подтверждения по каждому реагенту написано «есть X, купить Y».
• Панель у Джулии. Там тоже видно «докуп ~120g» или «всё в сумке», так что состояние ясно ещё до похода к аукциону.
• Команда /sup bag. Выводит в чат статус всех активных поставок.
Ограничения этой версии
• Банк не учитывается: в 3.3.5 его содержимое видно только при открытом банке.
• Если один реагент нужен нескольким поставкам, сумка считается для каждой отдельно, остаток между ними не делится.
Что ещё можно улучшить
1. Общий остаток между поставками. Один реагент не должен засчитываться дважды.
2. Кнопка «Докупить всё». Один выкуп недостающего по всем активным поставкам сразу.
3. Запоминание банка. Кэшировать его содержимое при посещении и учитывать как опцию.
4. Защита по цене. Не покупать дороже сметы плюс заданный процент; из планов версии 0.2 это пока не реализовано.
5. Выгода поставки. Награда за поставку минус стоимость докупки, чтобы сразу видеть, какие стоит брать.
6. Покупка по реальным лотам. Сейчас смета считается по минимальной цене за штуку, а стопки могут выйти дороже; точнее считать по стакану лотов.
7. Общая база поставок. Захардкодить её после /sup dump, чтобы аддон не нужно было «учить» на новом аккаунте.
Если что-то отобразится не так
Сделайте в игре /sup bag и /sup dump, затем /reload и пришлите результат — по нему можно будет поправить код.
